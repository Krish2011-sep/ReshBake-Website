# ReshBake Website Demo

A lightweight, static, mobile-first website for ReshBake — Oven Loves Flour, Nagpur.

## Tech
- Plain HTML
- Plain CSS
- Vanilla JavaScript
- Google Fonts
- No framework
- No build step
- No npm required

## Run locally
Just open `index.html` in a browser.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets/` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save.

GitHub Pages will publish the static site.

Replace demo gallery/product visuals with ReshBake's real photos and add only business-confirmed:

- menu

- logo/story
